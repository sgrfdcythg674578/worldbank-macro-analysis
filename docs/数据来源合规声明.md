# 数据来源合规声明

| 项目 | 内容 |
|---|---|
| 数据源名称 | 世界银行 World Development Indicators（WDI）开放数据 |
| 数据源URL | https://data.worldbank.org |
| 获取方式 | 官方指标页 Download → CSV 一次性下载（白名单方式，非爬虫） |
| 获取日期 | 2026-11-04 |
| 主数据源指标 | ① 人均GDP（NY.GDP.PCAP.CD）② GDP增速（NY.GDP.MKTP.KD.ZG）③ 通胀率（FP.CPI.TOTL.ZG）④ 失业率（SL.UEM.TOTL.ZS）⑤ 总人口（SP.POP.TOTL）⑥ 出口占GDP比重（NE.EXP.GNFS.ZS） |
| 授权/License | World Bank 开放数据遵循 CC BY 4.0（Creative Commons Attribution 4.0 International），允许复制、分发与学术使用，须注明来源 |
| 数据规模 | 原始下载 6 个指标CSV；合并后主表 17,556 行（266 国家/地区 × 1960–2025）；分析口径 218 国 × 2005–2024（5,320 行） |
| 抽样说明 | 未抽样（原始数据全部使用）；分析窗口收窄至 2005–2024 以控制早期缺失率（失业率/通胀率缺失由 53%/34% 降至 12% 左右） |
| 复用格式 | 清洗后数据导出为 CSV（data/clean/worldbank_macro_clean.csv，UTF-8），可继续导出JSON/SQLite |
